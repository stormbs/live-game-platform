🎮 Live Game TikTok

Nhập TikTok ID của bạn, chọn game, copy link overlay và dán vào TikTok LIVE Studio. Game nhận sự kiện live (like, bình luận, quà tặng) qua TikFinity — sau khi tạo phòng, mở dashboard của phòng để tải file TikFinity (.tfc) và xem hướng dẫn import (chỉ làm 1 lần).

✅ Room của bạn đã sẵn sàng

Đang kiểm tra trạng thái LIVE…

Mở dashboard để cài TikFinity (tải file .tfc của phòng rồi import vào TikFinity — chỉ làm 1 lần), cài đặt game, gửi event thử và reset phiên. Muốn đổi game: chọn game khác rồi bấm "Lấy link overlay" lại.

Cách chạy trong 4 bước

  1. Nhập TikTok ID, chọn game, bấm Lấy link overlay.
  2. Trong TikTok LIVE Studio: thêm nguồn Link (Browser Source), dán link overlay, đặt kích thước 1080 × 1920.
  3. Mở dashboard của phòng (link “Dashboard của streamer” ở trên) → mục 🎯 Cài đặt TikFinity: tải file TikFinity (.tfc) của phòng rồi import vào TikFinity — chỉ làm 1 lần, có cả cách tạo tay nếu file import lỗi.
  4. Bấm Go LIVE TRƯỚC, rồi mới bấm Connect trong TikFinity. Khán giả like / bình luận / tặng quà là game phản ứng ngay — số sự kiện trên dashboard phải > 0.
Lưu ý: Máy chủ chạy 24/7 trên Railway; sau mỗi lần deploy, đợi khoảng 1 phút rồi tải lại trang. Nguồn Link trong TikTok LIVE Studio đôi khi hơi lag; nếu cần mượt hơn, dùng OBS Virtual Camera. TikTok không có API LIVE chính thức nên kết nối có thể đổi theo thời gian; nếu game không nhận event, kiểm tra lại trạng thái LIVE trên trang này, chắc chắn link overlay dùng đúng TikTok ID của tài khoản đang live (nhập sai nick là game theo dõi nhầm tài khoản, không có event nào), và TikFinity đã Connect sau khi Go LIVE (xem hướng dẫn trên dashboard của phòng).
